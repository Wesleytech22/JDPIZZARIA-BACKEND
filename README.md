# JD Pizzaria — Backend (inicial)

```
npm install
npm run dev
```

Sobe em `http://localhost:3000`. Por enquanto só tem o necessário pro app do
Terminal funcionar: `POST /orders`, `GET /orders/:id`, `GET /orders`.

Conforme os outros apps forem entrando (Pizzaiolo, Motoboy, Web), este backend
cresce: catálogo dinâmico, mesas/comandas, motoboys, localização em tempo real,
chat, etc.
